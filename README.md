# 🎬 Netflix Content Strategy Analysis

## 📌 Project Overview
This project explores Netflix's global library to understand how the platform balances its content between Movies and TV Shows. The analysis focuses on genre popularity and regional growth hubs like India and South Korea.

## 🛠️ Tools & Technologies
- **Language:** Python (Pandas, Matplotlib)
- **Data Tools:** Microsoft Excel
- **Reporting:** PDF Data Report

## 📊 Key Insights
- **Global Reach:** 70% of content is Movies, while 30% consists of TV Shows.
- **Top Genre:** 'International Movies' and 'Dramas' are the leading categories.
- **Market Growth:** India is the second-largest content hub after the US.

## 📁 Files Included
- `Netflix_Titles_Data.csv`: Raw dataset used for analysis.
- `Netflix_Content_Analysis_Report.pdf`: Final visual report with charts.
